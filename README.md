# BoatPro

موقع بوت برو — منصة التقنية البحرية في المملكة والخليج.

## التشغيل محلياً

```sh
npm install
npm run dev
```

يفتح التطوير على المنفذ الذي يعرضه Vite (عادة `http://localhost:8080`).

## البناء

```sh
npm run build
npm run preview
```

الهوية البصرية الرسمية هي شعار BoatPro الموجود في `public/logo.png`.
